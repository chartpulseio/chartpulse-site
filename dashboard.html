Daily Bottom Reversal Scanner

Bottom zone + 2 of 3 sweep signals + reversal candle + next-candle confirmation. Gate events: liquidity sweep, BB sweep, CHoCH. Runs on closed daily candles — no repaint.

ENTRY = reversal candle confirmed by the next closed candle. PATTERN = candle formed, next candle decides. GATE = bottom + 2 of 3 signals, no candle yet. Zone-sweep stages use the live daily candle and can change before the daily close. No stop-loss or target is given; "cancel below" is where the setup is invalid. Rule-based screens, not financial advice; thresholds are starting values pending backtests.
